# AGI OS

Portal interno que organiza o trabalho da AGI Nanotech.

## O que faz
- Reúne as áreas e os projetos da empresa.
- Organiza documentos, decisões e tarefas.
- Acompanha editais de fomento.
- Conta com o apoio de agentes de inteligência artificial.

## Stack
Next.js · TypeScript · Tailwind CSS

## Status
Uso interno, em desenvolvimento. Código privado; este repositório é apenas uma vitrine.
